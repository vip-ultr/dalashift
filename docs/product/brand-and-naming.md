# Brand and Naming

**DalaShift is a working project name. It is not a final brand identity and
must not be presented as one.**

The name comes from the "Field Shift: Adapting Farms with NASA Data" challenge.
It is provisional pending team confirmation. The same status is recorded in the
[`README`](../../README.md) and the [`PRD`](../../PRD.md).

This document covers naming only. The visual identity, including the palette,
typography, component rules and the logo and favicon specification, is in
[`../build/BRAND.md`](../build/BRAND.md). The implemented interface standards
are in [`../design/design-system.md`](../design/design-system.md).
